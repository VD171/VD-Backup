## قائمة التحقق

- [ ] ترويسة لافتة المشروع موجودة على كل ملف مصدري جديد/مُغيَّر.
- [ ] الشفرة والتعليقات بالإنجليزية؛ لا شرطات em/en.
- [ ] إن تغيّر عنوان في الواجهة، فقد حُدّثت كل `lang/<code>.json` و`README.<code>.md`.
- [ ] لم تُضعَف أي ميزة حقيقية (الحفاظ على SELinux/uid-gid/الأوضاع، إلخ).
- [ ] الالتزامات موقّعة (`git commit -s`).
- [ ] تم الاختبار على جهاز/محاكي مروَّت (اذكر أيها).
