**المشكلة**
ما الذي تحاول فعله ولا يفعله VDBackup بعد؟

**الحل المقترح**
ما الذي تود حدوثه؟

**البدائل**
أي شيء فكّرت فيه.

**سياق إضافي**
الوجهات أو أوضاع النسخ الاحتياطي أو التطبيقات أو ROMs التي يتعلق بها هذا.
