# 행동 강령

우리는 VDBackup이 환영받는 프로젝트가 되기를 바랍니다. 서로 존중하고, 선의를
전제하며, 토론을 기술적이고 건설적으로 유지하세요.

- 친절하세요. 괴롭힘, 인신공격, 차별 금지.
- 사람이 아니라 아이디어와 코드를 비평하세요.
- 신규 참여자를 도우세요; 누구나 한때는 처음이었습니다.

받아들일 수 없는 행동은 유지관리자에게 비공개로 신고할 수 있습니다 (연락처는
[SECURITY.md](SECURITY.md) 참조). 유지관리자는 이 강령을 위반하는 댓글, 커밋,
이슈, 기여를 제거할 수 있으며, 반복 위반자를 차단할 수 있습니다.

이것은 Contributor Covenant의 정신을 프로젝트에 맞게 요약하여 각색한 것입니다.
