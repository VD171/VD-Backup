## چه

توصیف کنید این PR چه چیزی را تغییر می‌دهد و چرا.

## فهرست بررسی

- [ ] سربرگ بنر پروژه روی هر فایل منبع جدید/تغییریافته حاضر است.
- [ ] کد و کامنت‌ها به انگلیسی هستند؛ بدون em/en-dash.
- [ ] اگر یک برچسب رابط کاربری تغییر کرد، تمام `lang/<code>.json` و `README.<code>.md` به‌روز شدند.
- [ ] هیچ قابلیت واقعی (حفظ SELinux/uid-gid/modes و غیره) تضعیف نشد.
- [ ] کامیت‌ها امضا شده‌اند (`git commit -s`).
- [ ] روی یک دستگاه/شبیه‌ساز روت‌شده تست شد (بنویسید کدام).

## یادداشت‌ها

هر چیزی که بررسی‌کنندگان باید بدانند.
