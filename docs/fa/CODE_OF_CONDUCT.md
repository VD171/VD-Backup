# منشور رفتار

ما می‌خواهیم VDBackup یک پروژه پذیرا باشد. محترم باشید، حسن نیت را فرض بگیرید، و
بحث‌ها را فنی و سازنده نگه دارید.

- مهربان باشید. بدون آزار، حمله شخصی یا تبعیض.
- ایده‌ها و کد را نقد کنید، نه افراد را.
- به تازه‌واردها کمک کنید؛ همه زمانی تازه‌وارد بودند.

رفتار غیرقابل‌قبول را می‌توان به‌صورت خصوصی به نگهدارنده گزارش داد (برای تماس
[SECURITY.md](SECURITY.md) را ببینید). نگهدارندگان ممکن است کامنت‌ها، کامیت‌ها،
ایشوها و مشارکت‌هایی که این منشور را نقض می‌کنند حذف کنند، و ممکن است متخلفان مکرر را مسدود کنند.

این یک اقتباس فشرده و متناسب با پروژه از روح Contributor
Covenant است.
