# Gedragscode

We willen dat VDBackup een gastvrij project is. Wees respectvol, ga uit van goede trouw, en
houd discussies technisch en constructief.

- Wees vriendelijk. Geen intimidatie, persoonlijke aanvallen of discriminatie.
- Bekritiseer ideeën en code, geen mensen.
- Help nieuwkomers; iedereen was ooit nieuw.

Onaanvaardbaar gedrag kan privé worden gemeld aan de beheerder (zie
[SECURITY.md](SECURITY.md) voor contact). Beheerders mogen opmerkingen, commits,
issues en bijdragen verwijderen die deze code schenden, en mogen herhaalde overtreders bannen.

Dit is een verkorte, projectpassende aanpassing van de geest van de Contributor
Covenant.
