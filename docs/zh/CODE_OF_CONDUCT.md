# 行为准则

我们希望 VDBackup 成为一个友好的项目。请保持尊重，善意假定，
并让讨论保持技术性和建设性。

- 友善待人。不得骚扰、人身攻击或歧视。
- 批评想法和代码，而不是人。
- 帮助新人；每个人都曾是新手。

不可接受的行为可以私下向维护者报告（联系方式见
[SECURITY.md](SECURITY.md)）。维护者可以删除违反本准则的评论、提交、
issue 和贡献，并可以封禁屡次违规者。

这是对 Contributor Covenant 精神的一个浓缩的、适合本项目的改编。
