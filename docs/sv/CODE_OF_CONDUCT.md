# Uppförandekod

Vi vill att VDBackup ska vara ett välkomnande projekt. Var respektfull, anta god vilja och
håll diskussionerna tekniska och konstruktiva.

- Var vänlig. Inga trakasserier, personangrepp eller diskriminering.
- Kritisera idéer och kod, inte människor.
- Hjälp nykomlingar; alla var nya en gång.

Oacceptabelt beteende kan rapporteras privat till underhållaren (se
[SECURITY.md](SECURITY.md) för kontakt). Underhållare kan ta bort kommentarer, commits,
ärenden och bidrag som bryter mot den här koden, och kan banna återfallsförbrytare.

Detta är en kortfattad, projektanpassad anpassning av andan i Contributor
Covenant.
