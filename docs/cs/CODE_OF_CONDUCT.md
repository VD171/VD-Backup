# Kodex chování

Chceme, aby VDBackup byl přívětivý projekt. Buďte ohleduplní, předpokládejte dobré úmysly a
udržujte diskuze technické a konstruktivní.

- Buďte laskaví. Žádné obtěžování, osobní útoky ani diskriminace.
- Kritizujte nápady a kód, ne lidi.
- Pomáhejte nováčkům; každý byl jednou nový.

Nepřijatelné chování lze soukromě nahlásit správci (kontakt viz
[SECURITY.md](SECURITY.md)). Správci mohou odstranit komentáře, commity,
issues a příspěvky, které porušují tento kodex, a mohou zablokovat opakované narušitele.

Toto je zhuštěná adaptace ducha Contributor Covenant přizpůsobená projektu.
