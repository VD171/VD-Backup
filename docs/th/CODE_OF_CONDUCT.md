# จรรยาบรรณ

เราต้องการให้ VDBackup เป็นโครงการที่ต้อนรับทุกคน จงให้เกียรติกัน สันนิษฐานว่าทุกคนมีเจตนาดี
และรักษาให้การสนทนาเป็นเรื่องเทคนิคและสร้างสรรค์

- จงใจดี ไม่คุกคาม ไม่โจมตีส่วนตัว และไม่เลือกปฏิบัติ
- วิจารณ์ความคิดและโค้ด ไม่ใช่ตัวบุคคล
- ช่วยเหลือผู้มาใหม่ ทุกคนเคยเป็นมือใหม่มาก่อน

พฤติกรรมที่ยอมรับไม่ได้สามารถรายงานเป็นการส่วนตัวไปยังผู้ดูแลได้ (ดูช่องทางติดต่อใน
[SECURITY.md](SECURITY.md)) ผู้ดูแลอาจลบคอมเมนต์ commit
issue และการมีส่วนร่วมที่ละเมิดจรรยาบรรณนี้ และอาจแบนผู้ที่ทำผิดซ้ำ

นี่คือการปรับใช้แบบย่อและเหมาะกับโครงการ ตามเจตนารมณ์ของ Contributor
Covenant
