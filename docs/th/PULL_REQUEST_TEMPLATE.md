## อะไร

อธิบายว่า PR นี้เปลี่ยนอะไรและทำไม

## รายการตรวจสอบ

- [ ] banner header ของโครงการมีอยู่ในไฟล์ซอร์สทุกไฟล์ที่เพิ่ม/เปลี่ยน
- [ ] โค้ดและคอมเมนต์เป็นภาษาอังกฤษ; ไม่มี em/en-dash
- [ ] หาก UI label เปลี่ยน ได้อัปเดต `lang/<code>.json` และ `README.<code>.md` ทั้งหมดแล้ว
- [ ] ไม่มีฟีเจอร์จริง (การคงไว้ซึ่ง SELinux/uid-gid/modes ฯลฯ) ถูกทำให้อ่อนลง
- [ ] Commit ถูก sign off (`git commit -s`)
- [ ] ทดสอบบนอุปกรณ์/อีมูเลเตอร์ที่ root แล้ว (ระบุว่าเครื่องใด)
