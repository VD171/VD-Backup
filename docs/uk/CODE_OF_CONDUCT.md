# Кодекс поведінки

Ми хочемо, щоб VDBackup був привітним проєктом. Поводьтеся шанобливо, припускайте добрі
наміри й тримайте обговорення технічними та конструктивними.

- Будьте доброзичливими. Жодних переслідувань, особистих нападок чи дискримінації.
- Критикуйте ідеї та код, а не людей.
- Допомагайте новачкам; колись кожен був новачком.

Про неприйнятну поведінку можна повідомити супровідникові приватно (контакт див. у
[SECURITY.md](SECURITY.md)). Супровідники можуть видаляти коментарі, коміти,
issue та внески, що порушують цей кодекс, і можуть блокувати тих, хто порушує повторно.

Це стислий, доречний для проєкту варіант духу Contributor
Covenant.
