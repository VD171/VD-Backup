## Checklist

- [ ] हर नई/बदली गई source file पर project banner header मौजूद है।
- [ ] Code और comments अंग्रेजी में हैं; कोई em/en-dashes नहीं।
- [ ] अगर एक UI label बदला, तो सभी `lang/<code>.json` और `README.<code>.md` अपडेट किए गए।
- [ ] किसी real feature (SELinux/uid-gid/modes preservation, आदि) को कमजोर नहीं किया गया।
- [ ] Commits signed off हैं (`git commit -s`)।
- [ ] एक rooted device/emulator पर tested (बताएं कौन सा)।
