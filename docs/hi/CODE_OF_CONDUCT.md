# आचार संहिता

हम चाहते हैं कि VDBackup एक स्वागत करने वाला प्रोजेक्ट हो। सम्मानजनक रहें, सद्भावना मानें,
और चर्चाओं को technical और रचनात्मक रखें।

- दयालु रहें। कोई उत्पीड़न, व्यक्तिगत हमले, या भेदभाव नहीं।
- विचारों और code की आलोचना करें, लोगों की नहीं।
- नए लोगों की मदद करें; हर कोई कभी न कभी नया था।

अस्वीकार्य व्यवहार की रिपोर्ट निजी तौर पर maintainer को की जा सकती है (संपर्क के लिए देखें
[SECURITY.md](SECURITY.md))। Maintainers उन comments, commits,
issues और contributions को हटा सकते हैं जो इस संहिता का उल्लंघन करते हैं, और बार-बार
उल्लंघन करने वालों पर प्रतिबंध लगा सकते हैं।

यह Contributor Covenant की भावना का एक संक्षिप्त, project-appropriate रूपांतरण है।
