# 行動規範

私たちは VDBackup を歓迎されるプロジェクトにしたいと考えています。敬意を持ち、善意を前提とし、
議論を技術的かつ建設的に保ってください。

- 親切に。ハラスメント、個人攻撃、差別は禁止です。
- 人ではなく、アイデアとコードを批評してください。
- 新参者を助けてください。誰もがかつては新人でした。

容認できない行為は、メンテナに非公開で報告できます（連絡先は
[SECURITY.md](SECURITY.md) を参照）。メンテナは、この規範に違反するコメント、コミット、
issue、コントリビューションを削除することができ、常習的な違反者を追放することができます。

これは、Contributor Covenant の精神を、簡潔にプロジェクトに合わせて適応させたものです。
